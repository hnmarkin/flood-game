# Preparation action overlay prototype

Created "PA-preparation-action-overlay.html" as a self-contained UI prototype based on the supplied Riverton reference. It defaults to a close visual match and includes two alternate planning layouts behind ?variant=B and ?variant=C, plus selection, locked-state, confirm, close/reopen, toast, and keyboard variant switching. It uses the existing Background_Graphic.png for the map context.

If approved, production follow-up likely belongs in a UI Toolkit Preparation Actions screen/controller, wired to PrepActionService, resource/time state, the game-phase FSM, and the shared forecast/infrastructure data.
