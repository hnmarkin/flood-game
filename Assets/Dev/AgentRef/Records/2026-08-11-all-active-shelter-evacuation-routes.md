Expanded the simplified evacuation prototype to build routes for every active placed shelter. `EvacuationController` now loops all active shelters, builds one route per associated zone, logs per-shelter and total route counts, and keeps route selection as a lightweight preview-only guard with Inspector limits. `EvacuationRouteVisualizer` logs batch route counts and supports clear-then-draw flows. `ShelterManager` now owns an Inspector shelter placement cap, with helper methods and registration safeguards; `ShelterCandidateController` checks the cap before placing.
